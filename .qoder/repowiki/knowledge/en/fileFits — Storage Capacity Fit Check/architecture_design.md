Single-purpose module with two layers: `solution.js` exposes the `fileFits(capacity, used, size)` predicate (returning a boolean based on `size <= capacity - used`), while `knowledge.md` extracts reusable problem-solving patterns around boundary comparisons and idiomatic boolean returns in JavaScript. The solution is intentionally non-idiomatic in code to illustrate the anti-pattern documented in `knowledge.md`, which then recommends replacing it with a direct comparison return. No build manifest or package configuration exists; this is a standalone exercise artifact.
