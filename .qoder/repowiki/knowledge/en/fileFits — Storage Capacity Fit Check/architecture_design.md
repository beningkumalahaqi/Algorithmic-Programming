Standalone exercise artifact with two layers: `solution.js` exposes the intentionally non-idiomatic `fileFits(capacity, used, size)` predicate (boolean laundering via if/else), while `knowledge.md` extracts reusable problem-solving patterns around boundary comparisons and direct boolean-return style. `review.md` provides a structured review covering correctness, edge cases, complexity analysis, and recommended stylistic changes; `solution.md` holds the worked-out solution. No build manifest or package configuration exists — it is executed directly with Node from the repository root alongside sibling exercises.
