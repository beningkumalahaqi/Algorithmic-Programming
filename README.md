# Algorithmic Programming

Solutions to algorithmic challenges, with reasoning, reviews, and reusable lessons.

## Layout

Each problem has its own folder:

```text
<problemName>/
├── solution.js     # Original submission
├── solution.md     # Problem analysis and solution
├── review.md       # Correctness, edge cases, performance, and style
└── knowledge.md    # Reusable lessons
```
